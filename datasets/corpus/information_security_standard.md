# Information Security Standard (Northwind Aerospace — fictional)

## Access control
Access to controlled technical data requires multi-factor authentication. Access rights are reviewed every 90 days by the data owner.

## Incident reporting
Employees must report suspected security incidents to the Security Operations Center within 1 hour of discovery. Incidents involving controlled unclassified information are reported to the customer within 72 hours.

## Encryption
Data at rest is encrypted with AES-256. Data in transit uses TLS 1.2 or higher.

## Third-party risk
Suppliers that handle controlled data must complete a security assessment before contract award and every 12 months after.
